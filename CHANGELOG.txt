v0.6.6 - Release
--------------------------------------------------------------------------------

 [CHANGED] Added Anniversary TBC client interface 20506 support

v0.6.5 - Release
--------------------------------------------------------------------------------

 [NEW] iSealTwist promo/settings tab in Other Addons sidebar
 [CHANGED] Opening settings now closes other addon settings panels

v0.6.4 - Release
--------------------------------------------------------------------------------

 [NEW] Default WoW Sounds
  - One-click "Add Default WoW Sounds" button in the Sounds tab
  - 20 curated built-in game sounds (Raid Warning, Ready Check, Level Up, etc.)
  - Uses WoW's native PlaySound API — no files required
  - Stored as "wow:ID" format, played via SoundKit IDs

 [NEW] WAV file support
  - .wav files now accepted when adding sounds (16-bit PCM required by WoW)

v0.6.3 - Release
--------------------------------------------------------------------------------

 [CHANGED] TBC version detection boundary updated (20500 split)

v0.6.2 - Release
--------------------------------------------------------------------------------

 [CHANGED] Retail 12.0 secret value handling
  - Replaced pcall guards with issecretvalue() for ~10x better performance
  - Secret values in cooldown tracking trusted as "on cooldown" (like MSA pattern)
  - C_Secrets.ShouldSpellAuraBeSecret() used for whitelist checking during combat
  - ScanPlayerAuras() uses spell cache fallback for secret aura names
  - BuildAuraSpellCache() guards against secret values
  - UNIT_SPELLCAST_SUCCEEDED spellID is NeverSecret — pcall removed entirely

 [NEW] Cooldown Alerts — custom duration (retail 12.0+ only)
  - Per-spell duration field in Cooldown Alerts settings
  - Used as poll delay when real cooldown duration is secret during combat
  - Without it, falls back to 5s default poll interval

v0.6.1 - Release
--------------------------------------------------------------------------------

 [FIX] GetSpellCooldown replaced with version-safe wrapper
  - Uses C_Spell.GetSpellCooldown on retail 11.0+ / Midnight 12.0+
  - Falls back to GetSpellCooldown on Classic Era / TBC / Wrath / Cata / MoP
